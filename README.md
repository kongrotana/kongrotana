## 👋 About Me

<img align="right" width="320" src="https://readme-typing-svg.demolab.com?font=Fira+Code&size=14&duration=3000&pause=1000&color=7F52FF&width=320&height=60&lines=while(alive)+%7B+code();+%7D;Preserving+Khmer+culture+with+tech" alt="tagline"/>

I build everything from Android apps and Telegram bots to desktop software and custom Khmer fonts, passionate about bringing modern technology to Khmer users.
